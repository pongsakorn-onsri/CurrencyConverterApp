# CurrencyConverterApp
**CurrencyConverter** is an application developed by Pongsakorn Onsri to fulfill a specific business requirement.

**CurrencyConverter** was created as an iOS application utilizing expertise in the MVVM Architecture, Dependency Injection, Swift Combine, Concurrency, Unit Testing, and other relevant technologies.

## Prerequisite 
* Xcode 16 (required for Testing framework)
* iOS SDK (18 or upper) `download extra from Xcode`

## Dependency
No dependency for this app. I keep in mind to make it simple for run by no need to depend on other external frameworks or libraries.

## How to run
1. Open `CurrencyConverter.xcodeproj` with Xcode
2. Select scheme `CurrencyConverter` at the top of Xcode
3. Select `Product -> Run` or press `CMD + R`

## How to run tests
1. Open `CurrencyConverter.xcodeproj` with Xcode
2. Select scheme `CurrencyConverter` at the top of Xcode
3. Select `Product -> Test` or press `CMD + U`
4. Show the result in `View -> Navigator -> Tests` or press `CMD + 6`
